## 회수

- **49화 공개 책임 심리 개시** → 로잘린·리타·기록관·관계자들이 발루아 대살롱 공개 자리에 섬.
- **같은 첫 획=동일 작성자 여부** → 필압 차이와 바늘구멍으로 동일 작성자 확정 불가. 같은 본을 모사한 글씨 가능성으로 정정.
- **첫 장 절취 장소** → 포장 서기의 칼·표지 풀·푸른 천실로 포장실 확정.
- **제본·포장 관계자의 능동 행동** → 포장 서기가 도주했으나 리타에게 붙잡힘.
- **로잘린의 새 사실 하나** → 비밀 증표를 공작가 봉함 입회자에게 받았다는 진술이 포장실 섬유·서기 증언으로 확인.
- **로잘린의 새 거짓 하나** → 첫 장 절취를 발루아에서 처음 알았다는 진술이 본인 필체의 ‘첫 장은 따로’ 지시 쪽지로 반박됨.
- **아드리안의 49화 새 수** → 공작저 비밀 공개와 세실리아 단독 입회를 결합했으나 세실리아가 봉함실 물건을 공개 자리로 옮기게 해 차단.
- **황실 재정감독관의 첫 입성** → 발루아 저택에 실제 들어와 가족 서신 열람을 시도함.
- **재정감독관의 첫 범위 확장 저지** → 디미트리 부서 정본으로 지급 대조가 가능함을 세워 가족 서신 접근을 1차 차단.
- **디미트리와의 첫 공개 이해 충돌** → 변경 지급 우선 요구와 서재 보호가 충돌했으나 부서 정본을 칼집으로 쓰는 절충 성립.
- **48화 장부의 원래 장수와 절취 단계 1차** → 속지 마흔여덟 장 확인 뒤 표지 부착 전 절취.
- **공작저 봉함 전 접근 범위 1차 축소** → 제본장·조수, 포장 서기, 공작가 봉함 입회자로 축소.
- **로잘린이 남에게 넘기지 않은 패** → 은매 머리핀 속 비밀 증표 공개.
